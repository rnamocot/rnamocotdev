# Renie Namocot: Portfolio

A static, SEO-first portfolio site. The pages are generated by `build.py`, so there's no framework, no database, and the HTML loads fast and is easy to crawl.

## Commands

```bash
python build.py            # build the site into ./public
python build.py --serve    # build + preview at http://localhost:5173
```

Deploy the **`public/`** folder to any static host, such as Netlify, Vercel, Cloudflare Pages or cPanel.

## Before going live

1. In `build.py`, set `SITE_URL` to your real domain. Canonical URLs, the sitemap, schema and `llms.txt` all use it.
2. In `build.py`, add your LinkedIn, GitHub and Upwork profile URLs to `SAME_AS`. This helps Google and AI assistants recognise you as one person (an entity).
3. Replace the placeholder plugins in `src/content/plugins.py` with your real ones.
4. After launch, submit `https://YOURDOMAIN/sitemap.xml` in Google Search Console and Bing Webmaster Tools.

## Where to edit content

| What | File |
|---|---|
| Homepage sections | `src/pages/home.html` |
| Service pages (`/services/<slug>/`) | `src/content/services.py` |
| Blog posts (`/blog/<slug>/`) | `src/content/blog.py` |
| Plugin store (`/plugins/<slug>/`) | `src/content/plugins.py`. Set `status: "available"`, `price` and `buy_url` to start selling |
| Portfolio projects | `src/data/projects.json`, with screenshots in `assets/img/work/` |
| Privacy policy & terms (`/privacy/`, `/terms/`) | `src/content/legal.py`. Update `LEGAL_UPDATED` in `build.py` when you change them |
| Google Analytics + cookie banner | Set `GA4_ID` in `build.py`. Leave it `""` for no analytics and no banner |
| Styles / scripts | `assets/css/style.css`, `assets/css/fonts.css` (self-hosted fonts), `assets/js/main.js` |

After any change, run `python build.py` again.

## Images: self-hosted and optimised automatically

Building requires Pillow (`pip install pillow`).

**Originals** live in `src/media/` and are *not* deployed:
- `src/media/stock/<unsplash-id>.jpg`: stock photos (downloaded automatically the first time an id is used)
- `src/media/work/<site>.jpg`: full-size project screenshots

**On every build**, `build.py`:
1. Generates cropped WebP variants: stock photos at 480/800/1200/1800px (3:2) and screenshots at 480/800/1200px (16:10). Only new or changed originals are processed.
2. Adds `srcset`, `sizes`, `width` and `height` to every `<img>`, so each device downloads the smallest file that still looks sharp and the layout doesn't shift.
3. Makes 1200×630 JPG share images (`assets/img/og/`) for Facebook, LinkedIn and X, plus a branded default card.
4. Lazy-loads below-the-fold images, and loads hero images eagerly with `fetchpriority="high"` and a matching preload.

**To add a project screenshot:** save a 1440×900 (or larger) JPG/PNG as `src/media/work/<name>.jpg`, then set `"src": "/assets/img/work/<name>-1200.webp"` in `src/data/projects.json`.
**To add a stock photo:** use its Unsplash id (e.g. `photo-1498050108023-c5249f4df085`) in an `img` field.

Brand icons (`assets/img/icons/`, SVG) and flags (`assets/img/flags/`, SVG) are also downloaded once and self-hosted.

## SEO files generated on every build

| File | Purpose |
|---|---|
| `sitemap.xml` | Every indexable page with `lastmod`, plus image entries (Google Images) |
| `/sitemap/` | A readable HTML sitemap for visitors, linked in the footer |
| `robots.txt` | Allows all search engines and AI crawlers, blocks `404.html`, points to the sitemap |
| `404.html` | A helpful not-found page (`noindex`) with popular services and articles |
| `llms.txt` / `llms-full.txt` | Summary and full text of the site for AI assistants (ChatGPT, Claude, Perplexity) |
| `blog/rss.xml` | RSS feed for the blog |
| `favicon.ico`, `apple-touch-icon.png`, `site.webmanifest` | Icons for Google results, browser tabs, phones |
| `/.well-known/security.txt` | Security contact (RFC 9116), a trust signal |
| `<INDEXNOW_KEY>.txt` | IndexNow ownership key |
| `.htaccess` | HTTPS + non-www redirect, 404, gzip, browser caching (Apache/cPanel hosts) |

### After uploading

1. **Google Search Console:** add `rnamocotdev.com`, choose the *HTML tag* method, paste the `content` value into `GOOGLE_SITE_VERIFICATION` in `build.py`, rebuild, upload, then click *Verify*. Submit `sitemap.xml`.
2. **Bing Webmaster Tools:** do the same with `BING_SITE_VERIFICATION` (or import from Google Search Console). Bing also powers ChatGPT search.
3. **IndexNow:** after each upload, run `python build.py --indexnow` to notify Bing, Yandex and others about all your URLs immediately.

## SEO built in

- Unique `<title>`, meta description, canonical URL, Open Graph and Twitter cards on every page
- JSON-LD schema: Person, ProfessionalService, WebSite, Service, FAQPage, BlogPosting, BreadcrumbList, SoftwareApplication, CollectionPage
- `sitemap.xml`, `robots.txt` (allows Google, Bing and the AI crawlers GPTBot, ClaudeBot, PerplexityBot and others), `llms.txt` and a blog RSS feed
- All content rendered into the HTML, with no JavaScript needed to read it
- Answer-first intros and FAQs on service pages, a table of contents, author box and dates on posts
- Internal links between services, projects and articles
- Lazy-loaded images with explicit dimensions, WebP project screenshots, and preloaded hero images
